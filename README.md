# Путь Дракона — программа поездки с аудиозаданиями

Статический сайт (PWA) без сервера и фреймворков. Три раздела (кнопки внизу): **Программа** — 8 дней (24–31 октября 2026, группа СНГ, Пекин — Хайнань) с аудиозаданием на каждый день, открывается в 05:00 по Пекину в свой день; **Участники** — список с фото и банком; **Контакты** — организаторы и отели. Всё скачивается заранее и работает в авиарежиме.

```
index.html      страница
style.css       стили (цвета и шрифты из PDF программы)
app.js          тексты программы (TRIP, DAYS, CONTACTS, PLACES) + логика
tasks.json      аудиозадания по дням — заполняется через админ-панель
participants.json  список участников — заполняется через админ-панель
sw.js           service worker, версия кэша
manifest.json   иконка и название для экрана «Домой»
assets/img      обложка и фото дней (вырезаны из PDF)
assets/audio    записи d1.mp3 … d8.mp3 (сейчас тестовые, голос робота)
assets/fonts    Oswald и Montserrat с кириллицей, локально
```

## Как выложить

**GitHub Pages (для теста).** Создать репозиторий, загрузить содержимое папки (не саму папку, а `index.html` и остальное в корень), Settings → Pages → Branch: main, / (root). Через минуту сайт будет на `логин.github.io/репозиторий/`. Все пути относительные, подпапка не мешает.

**Важно про эту группу.** Участники из Беларуси, Грузии, Кыргызстана, Казахстана, Узбекистана и Азербайджана, поэтому российские блокировки (Netlify, Cloudflare) их не касаются. Узкое место — Китай: github.io там открывается нестабильно или не открывается вовсе. Пока все скачали гид дома, это не страшно. Но кто не скачал заранее — в Китае без VPN уже не скачает, и обновления программы во время поездки до людей не дойдут. Если нужна возможность обновлять гид на месте, финальную версию лучше положить на хостинг, доступный из Китая (например, VPS в Гонконге).

**Публичность.** В публичном репозитории любой, кто знает адрес, может открыть `assets/audio/d5.mp3` напрямую. Замок в интерфейсе мягкий (см. ниже). Если сюрприз важен — приватный хостинг и неочевидные имена файлов.

Сайт обязательно должен открываться по **https**, иначе оффлайн-режим не работает.

## Как поменять контент

Всё в начале `app.js`.

**Записи** — через админ-панель, см. следующий раздел. В `app.js` их нет.

**Параметры записей:** mp3 или m4a, 64–96 kbps, моно. 10 минут речи при 64 kbps — около 5 МБ. Гид не пережимает аудио, файл кладётся как есть; если больше 15 МБ, панель предупредит.

**Время открытия.** По умолчанию — `TRIP.unlockTime` («05:00») в дату дня по пекинскому времени (`TRIP.tzOffset` = +08:00). Отдельному дню можно задать своё: `task: { …, unlock: "2026-10-29T07:00:00+08:00" }`. Время всегда хранится с часовым поясом, поэтому телефон, оставшийся на минском или ташкентском времени, откроет задание в правильный момент. На карточке замка в таком случае подписано, когда это по часам телефона.

**Подзаголовок задания.** `task.hint` — короткая строка под «Задание дня» после открытия (например, «Послушайте в автобусе по дороге к стене»). Пусто — стоит нейтральная фраза.

**Программа и тексты.** `schedule` — строки `["время", "что", true]`, где `true` делает строку красной. Перенос во времени — `\n` (`"13:00–\n14:00"`). В `text` абзац с `**` в начале — жирный, с `!!` — красный акцент.

## Админ-панель: задания и участники

Сервера нет, поэтому схема такая: правите в гиде на своём телефоне (или в браузере на компьютере — там удобнее выбирать файлы), гид тут же всё показывает вам как есть, а участники получают правки после того, как вы выложите «пакет для сайта».

**Включить:** удерживать обложку 1,5 секунды → пароль. В этом режиме все задания открыты, а под карточкой каждого дня появляется «Изменить задание».

**Аудиозадание дня.** «Изменить задание» → «Выбрать запись» (mp3 или m4a с телефона или компьютера) → при желании заголовок, подпись после открытия и галочка «Открыто всегда — для теста» → «Сохранить». Запись сразу сохраняется на этом телефоне и играет, можно проверить. У дня 1 сейчас стоит галочка «Открыто всегда» — снять перед поездкой. «Убрать запись» → карточка «Запись готовится».

Файлы получают имена вида `d3-mvgr2rk0.mp3` — уникальные, поэтому при замене записи телефоны участников увидят новый файл как несохранённый и предложат «Докачать», а старый удалят сами. Переименовывать вручную ничего не нужно.

**Участники.** Раздел «Участники» → «Редактировать список». Фото из галереи или камеры (гид сожмёт до 192×192, около 8 КБ), ФИО, Банк (подсказывает уже введённые). Карандаш — изменить, корзина — удалить. Список показывается одним списком по алфавиту, банк — подписью под именем. 40 человек с фото — около 350 КБ. Сейчас в файле три примера, удалите их.

**Выложить на сайт.** Пока правки не выложены, в плашке статуса и в разделе участников висит жёлтая плашка. «Скачать пакет для сайта» → zip с `tasks.json`, `participants.json` и новыми аудиофайлами по правильным путям → распаковать в корень сайта поверх старых файлов → закоммитить. Версию кэша поднимать не нужно: оба json гид берёт с сервера при каждом открытии с интернетом, а аудио — по кнопке «Докачать». После выкладки нажмите «Правки уже выложены», чтобы телефон снова читал файлы с сайта.

На компьютере в режиме организатора всё то же самое: откройте сайт в Chrome, удерживайте обложку мышью.

## Контакты

`CONTACTS` в `app.js`: имя, роль, телефон (в международном формате — становится кнопкой звонка), WeChat ID (кнопка копирует), Telegram. Пустое поле не показывается. Сейчас стоят заглушки — заменить.

`PLACES` — отели с китайским названием, чтобы показать таксисту. **Китайские названия проверить у принимающей стороны**, я их не сверял.

## После любой правки — поднять версию кэша

В `sw.js`: `const CACHE = "put-drakona-v1";` → `v2` → `v3`… И то же число в `app.js`, `TRIP.version` (оно видно внизу страницы — так легко проверить у человека, какая у него версия). Без этого у тех, кто уже открывал гид, останется старая страница. Новая версия подтянется при следующем открытии гида с интернетом; записи при этом не перекачиваются.

## Замок и режим организатора

Замок мягкий: кнопка появляется по часам телефона. Если человек переведёт часы вперёд, задание откроется раньше. Для настоящего сюрприза нужна другая схема (шифрование записей и «код дня», который называет гид) — можно добавить.

**Открыть всё на своём телефоне** (проверка записей, сдвиг программы): удерживать обложку наверху 1,5 секунды → пароль `drakon2026` → все задания открыты. Выключается ссылкой в плашке статуса. Действует только на этом телефоне.

Сменить пароль: получить хеш и вставить в `TRIP.orgHash`.
- Mac/Linux: `echo -n 'новыйпароль' | shasum -a 256`
- Windows PowerShell: `$s=[Text.Encoding]::UTF8.GetBytes('новыйпароль'); -join ([Security.Cryptography.SHA256]::Create().ComputeHash($s) | % { $_.ToString('x2') })`

## Что умеет гид

- «Скачать всё»: записи по одной, с прогресс-баром; уже скачанные пропускаются, поэтому после обрыва кнопка «Докачать» качает только остальное. После — запрос на постоянное хранение (`navigator.storage.persist`).
- Плашка статуса: «Записи ещё не сохранены» / «Сохранено N из M» / зелёная «Все записи сохранены». Красная — если записи были сохранены полностью, а потом часть пропала (очистка памяти).
- Аудио хранится в IndexedDB как blob, не в Cache API (у Safari проблемы с аудио через service worker).
- Сегодняшний день открывается автоматически (по пекинской дате); до поездки — день 1, после — день 8.
- Когда наступает 05:00 и гид открыт, задание открывается само, без перезагрузки.
- Плеер снизу: пауза, ±15 секунд, перемотка; название и картинка на экране блокировки.
- iPhone: если гид открыт не с экрана «Домой», показывается подсказка, как его туда добавить. Android: кнопка «Установить на телефон», если Chrome её предлагает.

## Чек-лист перед раздачей участникам

1. Открыть ссылку с мобильного интернета и с Wi-Fi — в Беларуси, Казахстане, Узбекистане, Кыргызстане, Грузии, Азербайджане (попросить по человеку из каждой страны).
2. iPhone: Safari → «Поделиться» → «На экран „Домой“» → открыть **с иконки** → «Скачать всё» → зелёная плашка.
3. Android: Chrome → «Установить» или «Добавить на гл. экран» → открыть с иконки → «Скачать всё».
4. Включить авиарежим, закрыть гид из списка приложений, открыть снова — программа и картинки на месте.
5. Режим организатора → включить запись в авиарежиме. Погасить экран — звук продолжается, на экране блокировки видны название и картинка, пауза работает.
6. Перезагрузить телефон, открыть гид в авиарежиме — зелёная плашка на месте.
7. Выключить режим организатора — задания снова под замком с правильной датой открытия.
8. Снять галочку «Открыто всегда» у дня 1, заменить заглушки в `CONTACTS`, удалить примеры из участников, выложить пакет.
9. Проверить версию внизу страницы.

**Когда рассылать:** за 3–7 дней до вылета, с напоминанием открыть гид с иконки накануне вылета, пока есть домашний интернет. Скачивание — по Wi-Fi.
